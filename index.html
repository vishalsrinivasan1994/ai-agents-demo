Today, in 26R2, AI Agents can:

  • Generates case closure notes

  • Creates opportunity summaries

  • ...and much more

All of this happens within Acumatica's boundaries.

Acumatica · 27R1

In 27R1, AI Agents can do much more.

Please trigger the pre-built agent to fill the stock item description.

With 27R1, AI Agents can use web search and web fetch tools, which unlocks numerous use cases.

Tool calling lets an agent decide which tool to use, such as web search, and act on the result.

The ask

Think of a task in your daily work that would be easier if an agent could look things up on the web. Bring us one real scenario and we will build the agent with you in AI Agents. One of these will ship prebuilt in 27R1, so web search gets proven on real work, not just in a demo.
